# Bunny Reads 🐰🎀

A cute, original phonics web app for early readers, starring **Bella Bun** — an original mascot (not based on any existing character), free to use and sell.

Same activities as the base app — Letter Match, Sound Teams, Sight Words, Word Blocks, Read & Learn — in a pink-and-cream kawaii theme. No audio, installable to any phone's home screen, works offline.

## Run / deploy
Static site — drop the folder on Vercel, Netlify, or GitHub Pages. No build step.

## Mascot
Bella Bun is a plain inline SVG in `index.html` (search `class="bun"`). Recolor or restyle freely. All content (word lists, sound families, reading levels, sight words by grade) lives at the top of `index.html`.
